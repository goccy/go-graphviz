# Graphviz 15 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the vendored Graphviz in go-graphviz from 12.2.1 to 15.1.1 via four checkpoints, keeping the public Go API unchanged and every checkpoint green and committed to `master`.

**Architecture:** Graphviz C sources are compiled to a WASM binary (`internal/wasm/graphviz.wasm`) inside Docker (wasi-sdk 24). A generated C shim (`internal/wasm/build/bind.c`) exposes the graphviz API; it and the Go host bindings (`internal/wasm/bind.go`) are generated by the internal `nori` tool from `internal/wasm/bind.proto`, which mirrors C struct layouts and function signatures. The Go packages `cdt`/`cgraph`/`gvc` call the WASM via wazero. Upgrading = bump `graphviz.version`, fix `bind.proto` to match the new headers, regenerate, rebuild the WASM, fix Go code, test, commit.

**Tech Stack:** Go 1.23+, wazero, wasi-sdk 24 / binaryen 119 / expat 2.6.3 (Docker via OrbStack), buf v1.32.2, internal `protoc-gen-nori` generator, Graphviz C sources from GitLab generic packages.

## Global Constraints

- Target version: **15.1.1** (`graphviz.version`). Checkpoints, in order: **13.0.1 → 13.1.2 → 14.1.5 → 15.1.1**.
- Commit each checkpoint to `master` as `graphviz updated to X.Y.Z` (matches project history style).
- **No public Go API changes**: exported signatures in `cgraph`, `gvc`, `cdt` stay identical.
- **No changes** to the `internal/tools/nori` generator.
- **No toolchain bumps** (wasi-sdk 24, binaryen 119, expat 2.6.3, buf v1.32.2) unless a checkpoint forces one.
- Dockerfile stays the canonical build. `testdata/imagehash.json` is regenerated **only if** a hash test actually fails; prefer doing it at the final checkpoint.
- Every checkpoint ends with `go test ./...` green.
- The Docker build is a single clang invocation over all sources, so it is NOT incrementally cached by ccache; budget **~10–25 min per `make container/build`** (first one slower: base image + apt + downloads).
